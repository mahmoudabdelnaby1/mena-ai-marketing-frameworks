# Evidence Register & Source Boundaries — `FW-082`

Use current primary sources and the merchant's actual provider configuration. This framework makes no claim about a universal InstaPay checkout integration or fee level.

| Source to consult | What to verify |
|---|---|
| Merchant's bank or payment provider | Beneficiary information, payment confirmation source, fees, settlement, supported API/integration, and refund behavior. |
| E-commerce platform documentation | Order-state controls, webhook behavior, auditability, and customer notifications. |
| Merchant's settled transaction and order records | Reconciliation accuracy, exceptions, duplicates, and time to confirmation. |

Customer-entered references and screenshots are not proof of settlement. Use authorized records and a named human reconciliation owner.
