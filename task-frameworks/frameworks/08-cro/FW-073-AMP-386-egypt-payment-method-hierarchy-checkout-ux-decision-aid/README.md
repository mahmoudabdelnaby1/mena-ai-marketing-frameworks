# `FW-073` — Egypt Payment-Method & Checkout UX Decision Aid
## أداة قرار لترتيب وسائل الدفع وتجربة إتمام الطلب في المتجر المصري

- **One-Sentence Promise (EN)**: Choose and present payment methods using the merchant's supported providers, current fees, customer evidence, delivery operations, and reconciliation capacity.
- **الوعد التطبيقي في جملة واحدة (AR)**: اختر وسائل الدفع واعرضها وفق مزودي المتجر والرسوم الحالية وبيانات العملاء وعمليات التوصيل وقدرة تسوية المدفوعات.
- **Selected Artifact Type**: `DECISION_AID`
- **Intended Audience**: E-commerce, finance, and customer-experience teams.

## Use It When
Reviewing checkout payment choices, fees, payment instructions, or the relationship between payment status and order fulfillment.

## Quick Start
Measure current checkout completion and payment outcomes using your own records; verify provider availability, fees, and settlement behavior; prototype the simplest clear option set and test it with customers.

Do not treat external market-share estimates as a substitute for merchant-specific data.
