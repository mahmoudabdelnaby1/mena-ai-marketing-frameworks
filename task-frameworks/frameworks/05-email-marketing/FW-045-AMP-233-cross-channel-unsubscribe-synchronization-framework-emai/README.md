# `FW-045` — Cross-Channel Preference & Suppression Workflow
## سير عمل مزامنة تفضيلات العملاء وإيقاف الرسائل عبر القنوات

- **One-Sentence Promise (EN)**: Design and verify a reliable process for recording customer marketing preferences and propagating suppression across connected channels.
- **الوعد التطبيقي في جملة واحدة (AR)**: صمّم واختبر سير عمل موثوقًا لتسجيل تفضيلات التسويق ومزامنة إيقاف الرسائل عبر القنوات المتصلة.
- **Selected Artifact Type**: `OPERATING_FRAMEWORK`
- **Intended Audience**: CRM, lifecycle, and marketing-operations teams.

## Use It When
Adding a channel or vendor, changing CRM integrations, or reviewing how customer opt-out requests reach downstream send systems.

## Quick Start
Map all sources and destinations, define a shared suppression record, test propagation and retries, and retain an auditable event trail. Verify market and channel obligations separately.

This is an implementation workflow, not a determination of legal requirements.
