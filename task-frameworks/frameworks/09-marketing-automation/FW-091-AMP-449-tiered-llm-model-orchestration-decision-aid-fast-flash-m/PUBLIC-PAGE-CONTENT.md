# LLM Model Selection & Routing Decision Aid
## <span dir="rtl">أداة قرار لاختيار نماذج اللغة وتوجيه المهام بينها</span>

Choose and route model tasks by required capability, output quality, latency, privacy, cost, and fallback behavior—not by a fixed model ranking.

## Review sequence
1. Define the task, input/output modes, language needs, latency target, and allowed data.
2. Check current official model catalogs and account availability.
3. Evaluate candidates on representative, permitted examples using task-specific human-reviewed criteria.
4. Compare failure modes, latency, and cost assumptions using current provider documentation.
5. Define fallback and human review for uncertain or unavailable outputs.
6. Record the selected configuration and a date to reassess it.

## Boundary
Model names, capabilities, availability, limits, and prices change. This framework does not declare one model universally best or guarantee output quality.
