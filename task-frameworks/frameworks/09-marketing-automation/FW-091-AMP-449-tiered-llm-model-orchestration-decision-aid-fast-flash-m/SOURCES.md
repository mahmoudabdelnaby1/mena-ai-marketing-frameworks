# Evidence Register & Source Boundaries — `FW-091`

Use current official provider documentation and task-specific evaluation results. Model availability, limits, features, and pricing are time-sensitive.

| Evidence source | Use |
|---|---|
| Official model catalog and API documentation for each provider | Confirm current model IDs, supported modalities, limits, regions, and behavior. |
| Official pricing and data-handling documentation | Record current cost assumptions, retention, and data-use terms for the selected account and deployment. |
| Internal evaluation set and human review | Compare quality and failure modes for the actual task; do not generalize from vendor benchmarks alone. |

Re-check the catalog and repeat the evaluation when requirements or provider offerings change.
