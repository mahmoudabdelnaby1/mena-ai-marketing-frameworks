# `FW-091` — LLM Model Selection & Routing Decision Aid
## أداة قرار لاختيار نماذج اللغة وتوجيه المهام بينها

- **One-Sentence Promise (EN)**: Select and route model tasks by required capability, quality, latency, privacy, cost, and fallback behavior rather than by a fixed model ranking.
- **الوعد التطبيقي في جملة واحدة (AR)**: اختر النماذج ووجّه المهام حسب القدرات والجودة والسرعة والخصوصية والتكلفة وآلية البديل، لا وفق ترتيب ثابت للأسماء.
- **Selected Artifact Type**: `DECISION_AID`
- **Intended Audience**: AI product, marketing-operations, and engineering teams.

## Use It When
Choosing or changing a model for content, analysis, image, audio, or tool-using workflows.

## Quick Start
Define task requirements and data constraints, compare currently available models using a representative evaluation set, validate latency/cost and fallback, then re-check the provider catalog before production changes.
