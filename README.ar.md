# أطر تشغيل الذكاء الاصطناعي في التسويق

مكتبة ثنائية اللغة لأطر عملية تساعد الفرق على استخدام الذكاء الاصطناعي في عمليات التسويق الرقمي. تركز الأطر على سير عمل قابل للتكرار، والأدلة، ومسؤولية المراجعة، والحدود، وإمكانية التراجع عن القرارات. هذه وثائق إرشادية؛ لا تتضمن وكلاء قابلين للتشغيل أو نماذج مستضافة أو بيانات عملاء.

لكل إطار نسخة عربية وأخرى إنجليزية. استخدم النسخة الملائمة للعمل، وتأكد من بقائهما متوافقتين عند تعديل أي منهما.

## طريقة الاستخدام

1. اختر الإطار وفق المشكلة التشغيلية، لا اسم الأداة.
2. اجمع المدخلات المذكورة وحدد مسؤولًا بشريًا عن القرار.
3. اتبع الخطوات واحتفظ بسجل المراجعة المطلوب.
4. راجع المصادر الأولية ومتطلبات السوق والمنصة الحالية قبل التنفيذ.
5. سجل المسائل التي لم تُحسم بدل اعتبار نقص المعلومات موافقة.

## الحدود

هذه الوثائق إرشادات تشغيلية عامة، وليست مشورة قانونية أو خصوصية أو مالية ولا فتوى في سياسات المنصات. لا تضمن أداء الحملات أو الفهرسة أو ترتيب نتائج البحث أو الاقتباس في إجابات الذكاء الاصطناعي أو الامتثال. تتغير القوانين والسياسات وخصائص المنتجات وقدرات الأدوات؛ راجع المصادر الأولية الحالية واستعن بمختص للسوق المعني عند الحاجة. لا تمرر بيانات شخصية أو سرية أو خاصة بالعملاء إلى أداة ذكاء اصطناعي ما لم تعتمد المؤسسة الأداة واستخدام البيانات.
