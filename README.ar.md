# أطر مهام التسويق الرقمي

مكتبة عملية تضم **92 إطارًا مستقلًا لمهام محددة** عبر تسعة تخصصات في التسويق الرقمي. تحوّل مهام التسويق الواضحة إلى سير عمل وقوائم مراجعة وأدوات لاتخاذ القرار وأدلة تشغيل وقوالب أوامر. هذه مواد يستخدمها الفريق؛ وليست خدمة مستضافة أو وكلاء قابلين للتشغيل.

تشمل التخصصات التسعة تحسين محركات البحث (12 إطارًا)، والإعلانات المدفوعة، والتواصل الاجتماعي، والمحتوى، والبريد الإلكتروني، والتسويق عبر المؤثرين، وإعلانات الفيديو، وتحسين التحويل، وأتمتة التسويق (10 أطر لكل تخصص من التخصصات الثمانية الأخيرة). الفهرس هو المرجع المعتمد لعدد العناصر المنشورة.

## طريقة الاستخدام

1. اختر الإطار المطابق للمهمة.
2. أضف سياق العمل والمدخلات المطلوبة فعلًا.
3. اتبع سير العمل وكيّف المخرجات مع القناة والسوق والجمهور.
4. تحقّق من متطلبات المنصة والسوق المتغيرة بالرجوع إلى مصادر أولية حديثة.
5. اطلب مراجعة مسؤول بشري قبل استخدام المخرجات.

## الحدود

هذه المواد أدوات عمل عامة، وليست قرارات قانونية أو مالية أو متعلقة بالخصوصية أو سياسات المنصات أو الامتثال. قد تكون الأمثلة افتراضية، ولا ينبغي تقديمها كنتائج لعملاء. ولا تضمن أداء الحملات أو ترتيب نتائج البحث أو الفهرسة أو الاقتباس في إجابات الذكاء الاصطناعي. تحقّق من المتطلبات الحالية وعيّن مراجعًا بشريًا مؤهلًا قبل التنفيذ.
