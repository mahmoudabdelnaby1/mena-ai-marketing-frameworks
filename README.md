# AI Marketing Operating Frameworks

A bilingual, practical framework library for teams using AI across digital marketing operations. The collection focuses on repeatable workflows, evidence, review ownership, boundaries, and recoverable decisions. It is published as documentation; it does not contain executable agents, hosted models, or client data.

## How to use a framework

1. Choose the framework based on the operational problem, not the tool brand.
2. Gather the listed inputs and identify an accountable human owner.
3. Follow the workflow and retain the specified review record.
4. Check linked primary sources and current platform or market requirements before execution.
5. Record unresolved issues instead of treating missing information as approval.

## Boundaries

These documents are general operational guidance, not legal, privacy, platform-policy, or financial advice. They do not guarantee campaign performance, indexing, search rankings, AI citations, or compliance. Laws, platform policies, product features, and AI tool capabilities change. Recheck current primary sources and obtain qualified market-specific review where needed. Never put personal, confidential, or client data into an AI tool unless the organization has authorized the tool and data use.
